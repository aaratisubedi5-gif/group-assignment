Project Overview

Problem

Students often struggle to balance coursework, assessments, work, and personal responsibilities, leading to disorganisation, stress, and missed deadlines.

Proposed Solution

Sajilo Study Planner is a study planning and managing system that supports secure login, task management, scheduling, reminders, and progress tracking — including usability features like light/dark theme.

Scope

We implemented features defined in the scope statement and controlled scope creep.

In Scope

  • Login system setup
  • Task management + categorisation
  • Scheduling of study sessions
  • Task reminder system
  • Progress tracking
  • Admin controls
  • Task status management
  • Sorting by due date / priority
  • Theme switcher (dark/light)
  • Search bar tool
  • Priority assignments

Out of Scope

  • Mobile app
  • Real notifications
  • External integration

Deliverables

  • Business Case, Scope Statement, Project Charter
  • ERD (Mermaid + PNG), SQL Database
  • Gantt Chart, PPT Presentation

System Architecture

Architecture Summary

Sajilo follows a simple layered design: UI (user interaction), Application logic (rules and processing), and Database (persistent storage for users, tasks, schedules, reminders, and progress).

  • Focus on maintainability and clarity for handover
  • Database-backed features align with ERD and SQL tables

Database Design

Relational database supports tasks, scheduling, reminders, and progress logging.

Key Tables (7)

  • USERS: user account + role
  • CATEGORIES: subject/categories
  • PRIORITIES: priority types + weights
  • TASKS: tasks with due dates, status, user/category/priority
  • SCHEDULE_ENTRIES: planned sessions linked to tasks
  • REMINDERS: reminder timings for tasks
  • PROGRESS_LOG: progress percent + notes over time

Relationships (examples)

  • One USER creates many TASKS
  • CATEGORIES classify TASKS
  • PRIORITIES prioritise TASKS
  • One TASK can have many REMINDERS
  • One TASK can have many PROGRESS_LOG entries
  • TASKS can be linked to SCHEDULE_ENTRIES
